# AI vs ML vs DL

## Artificial Intelligence

Artificial Intelligence is the broad field of creating systems that perform tasks requiring intelligence.

## Machine Learning

Machine Learning is a subset of AI.

Instead of explicitly programming every rule, ML systems learn patterns from data.

Example:

A spam detection system learns from examples of spam and non-spam emails.

## Deep Learning

Deep Learning is a subset of Machine Learning that uses neural networks with multiple layers.

It is commonly used for:

- Image recognition
- Speech recognition
- Natural language processing
- Generative AI

## Relationship

Artificial Intelligence
│
└── Machine Learning
    │
    └── Deep Learning

## Simple Example

AI:
"Build a system that recognizes cats."

ML:
"Give the system many examples of cats and non-cats so it can learn patterns."

DL:
"Use a deep neural network to automatically learn complex visual features from the images."

## Generative AI

Generative AI refers to AI systems capable of generating new content.

Examples:

- Text
- Images
- Audio
- Video
- Code

Examples of generative AI applications include chatbots, image generators, and coding assistants.
